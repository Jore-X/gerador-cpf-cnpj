# CPFCerto

Gerador e Validador de CPF desenvolvido com **HTML, CSS e JavaScript puro**.

O projeto permite gerar números de CPF matematicamente válidos para testes e desenvolvimento, além de verificar se um CPF informado possui uma sequência de dígitos verificadores válida.

## 🚀 Funcionalidades

* Gerar CPF válido para testes
* Validar CPF
* Opção de gerar CPF com ou sem pontuação
* Copiar CPF gerado
* Bloqueio de sequências com todos os números iguais
* Interface responsiva para desktop e dispositivos móveis

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Google Fonts

O projeto não utiliza backend, banco de dados ou frameworks. Toda a lógica é executada diretamente no navegador.

## ⚠️ Aviso

Os CPFs gerados por esta ferramenta são destinados exclusivamente a **testes e desenvolvimento**.

Não utilize os números gerados para cadastros, identificação de pessoas ou qualquer finalidade que exija um CPF real.

## 🎯 Objetivo do projeto

O CPFCerto foi desenvolvido como um projeto prático para estudar e aplicar conceitos de desenvolvimento web utilizando JavaScript puro.

Além do aprendizado, o projeto também foi desenvolvido com foco em publicação na internet, SEO e geração de tráfego orgânico.
